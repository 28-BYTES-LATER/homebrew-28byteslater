# Homebrew Tap

To install publicly available 28 BYTES LATER software, first add this tap with
Homebrew already installed:

```sh
brew tap 28-BYTES-LATER/28byteslater
```

Supported Homebrew platforms are macOS 14 or later on Apple silicon or 64-bit
Intel, and Linux on ARM64/AArch64 or Intel x86_64. Individual packages may
have narrower requirements.
